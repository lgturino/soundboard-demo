## Soundboard for prototyping

A minimal soundboard website, in which you can upload MP3 files, play them, and choose a random number of sounds. 

## Development

This demo uses FastAPI for the backend https://fastapi.tiangolo.com/learn/

The frontend is just a singular html with js for communicating with the backend

You can run it locally by doing `uv run fastapi dev` and then accessing locaslhost:8000
